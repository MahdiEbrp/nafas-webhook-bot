**⚙️ راهنمای فیلدهای تنظیمات**

• key: نام یکتای فنی برای خواندن تنظیم در برنامه؛ پس از ساخت از این API قابل تغییر نیست.
• type: نوع داده؛ متن، عدد، روشن/خاموش، شیء، آرایه یا localized (چندزبانه). پس از ساخت قابل تغییر نیست.
• value: مقدار پایه؛ null مجاز نیست. متن و URL و شماره را دقیق وارد کنید.
• translations: مقدار فارسی/انگلیسی؛ در ویرایش، ارسال این فیلد ترجمه‌های قبلی را جایگزین می‌کند؛ زبان حذف‌شده از ورودی حفظ نمی‌شود.
• isActive: وضعیت انتشار در مصرف‌کننده‌هایی که این پرچم را رعایت می‌کنند؛ بعضی مسیرهای عملیاتی نقشهٔ خام تنظیمات را می‌خوانند، پس غیرفعال‌سازی تضمین خاموش‌شدن قابلیت نیست.
• displayOrder: ترتیب فهرست نمایش؛ مقدار کمتر زودتر، نه اولویت اجرای منطق.

⚠️ حذف می‌تواند باعث استفاده از مقدار پیش‌فرض یا نبود تنظیم شود؛ معادل false نیست. کش برخی مصرف‌کننده‌ها ممکن است تا حدود ۶۰ ثانیه مقدار قدیمی را نگه دارد.
